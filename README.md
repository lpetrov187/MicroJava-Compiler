# MicroJava Compiler

A complete compiler for the **MicroJava** language — a simplified, educational object-oriented language. Translates MicroJava source code (`.mj`) into bytecode (`.obj`) executable on the MicroJava virtual machine.

Built as part of the **PP1 (Principles of Programming Language Translators)** course at ETF Belgrade.

## Features

- Lexical analysis, parsing, semantic analysis, and code generation
- Namespaces with `::` scope resolution
- Classes with single inheritance (`extends`)
- Arrays with dynamic allocation (`new`)
- Static initialization blocks
- Control flow: `if/else`, `for`, `break`, `continue`, `return`
- Built-in I/O: `print`, `read`
- Strong static type checking

## Language Example

```java
program test

namespace Konstante {
    const int jedan = 1;
    const int pet = 5;
    {}
}

int a;
{
    void main()
        int bodovi;
    {
        bodovi = Konstante::jedan;
        bodovi = bodovi + Konstante::pet;
        print(bodovi);
        read(a);
    }
}
```

## Architecture

```
Source (.mj) → Lexer → Tokens → Parser → AST → SemanticPass → CodeGenerator → Bytecode (.obj)
```

| Component | File | Description |
|-----------|------|-------------|
| Lexer | `Yylex.java` | Generated by JFlex from `spec/mjlexer.lex` |
| Parser | `MJParser.java` | Generated by CUP from `spec/mjparser.cup` |
| Semantic Analysis | `SemanticPass.java` | Type checking, symbol table management |
| Code Generation | `CodeGenerator.java` | AST → MicroJava bytecode |
| AST Nodes | `ast/` | ~170 auto-generated node classes (Visitor pattern) |
| Counter Utility | `CounterVisitor.java` | Counts local variables and formal parameters |

## Dependencies

| Library | Purpose |
|---------|---------|
| `JFlex.jar` | Lexer generator |
| `cup_v10k.jar` | Parser generator |
| `symboltable-1-1.jar` | Symbol table (scope management) |
| `mj-runtime-1.1.jar` | MicroJava VM runtime and bytecode emission |
| `log4j-1.2.17.jar` | Logging |

## Build & Run

Requires **Apache Ant** and **Java**.

```bash
# Full build (lexer gen → parser gen → compile)
ant compile

# Run compiled bytecode (reads from input.txt)
ant runObj

# Run with debugger
ant debug

# Disassemble bytecode
ant disasm

# Regenerate lexer only
ant lexerGen

# Regenerate parser + AST only
ant parserGen
```

## Semantic Rules

- All variables must be declared before use
- Strong static typing — no implicit conversions
- Array indices must be of type `int`
- Only `int` variables support `++`/`--`
- Namespace members accessed via `Namespace::member`
- Methods must match their declared return type

## Output

The compiler produces a `.obj` bytecode file executable by the MicroJava runtime. Compilation logs are written to `logs/mj.log`.
